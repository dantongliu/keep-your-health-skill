# 🏥 keep-your-health (家庭健康档案管家) 使用说明

欢迎使用 **keep-your-health**！这是一个专为家庭打造的智能健康档案管理 Skill。
它可以帮你把晦涩难懂的体检报告、化验单，一键转换为**排版精美、通俗易懂、带有历史数据追踪的专属网页档案**。

---

## 🚀 1. 如何安装

只需向你的 AI 助手（如 WorkBuddy）发送以下这句话即可完成自动安装：

> “请帮我安装一个健康档案管理的开源技能，GitHub 链接是：`https://github.com/dantongliu/keep-your-health-skill.git`。安装完成后告诉我。”

*(AI 会自动拉取代码并配置好底层的高保真模板与交互逻辑。)*

---

## 💡 2. 如何使用

安装完成后，你只需像和朋友聊天一样与它交互：

### 第一步：唤醒管家
在对话框输入并发送：
> **`@keep-your-health 我要建档`**
> *(或者：我要创建健康档案 / 帮我更新体检报告)*

### 第二步：根据向导提示提供数据
它会主动问你：**“是需要新建用户档案，还是更新已有档案？”**

*   **如果是新建**：它会引导你提供家庭成员的姓名、年龄、核心病史。
*   **如果是更新**：它会直接让你发送最新的报告。

**🪄 魔法时刻：**
你不需要手动敲任何体检数据！直接把**体检单的照片、PDF 文件或检查结果截图**发给它，它会自动完成所有数据的识别和提取。

### 第三步：接收专属 HTML 档案
稍等片刻，AI 就会为你生成一份独立的 `.html` 格式健康档案（例如 `森森的健康档案.html`）。
直接在浏览器中打开，你将获得：
*   📊 **数据可视化**：自动生成新老数据的对比趋势图。
*   🩺 **大白话医学翻译**：把“LDL-C”、“回声欠均匀”翻译成你能看懂的健康建议。
*   ✨ **丝滑的微交互**：鼠标悬停在图表上会弹出数值气泡，点击列表会平滑展开深度解读。

---

## 🌟 3. 核心亮点

*   **全量解析，绝不偷工减料**：它不会只盯着你的“异常红字”，正常的指标也会被悉心收纳在档案底部的“安全舱”里。
*   **像素级的高保真 UI**：摒弃了简陋的文字表格，采用左右分栏、胶囊切换 Tab 的现代化前端界面。
*   **物理隔离，隐私安全**：生成的档案是纯本地 HTML 文件，掌握在你自己手里，不需要上传到任何第三方商业平台。

## 👀 4. 效果样例 (Demo)

为了让你直观感受到这个 Skill 的强大，我们在项目中内置了一个真实的生成样例文件。

你可以直接下载或在浏览器中打开 [examples/demo-report.html](examples/demo-report.html) 进行体验。
在这个样例中你可以亲自操作：

## 📝 常见问题 (FAQ)

**Q: 只能处理体检报告吗？**
A: 不局限于年度体检，平时的门诊抽血化验单、B超报告单，都可以拍照发给它，它会自动将新数据合并进该成员的长期时间线中。

**Q: 如何查看历史趋势？**
A: 只要你持续把某位成员的新报告交给它，它会自动把历次数据串联起来。在界面的右侧会生成直观的横向对比图表，代谢变好还是变差一目了然。
